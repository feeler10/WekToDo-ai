# WekToDo-ai

WekToDo-ai 项目的初始仓库。目前仅完成项目骨架，业务需求和技术方案将在后续阶段逐步明确。

## 目录结构

```text
WekToDo-ai/
├── docs/
│   └── PROJECT_TASK_BOOK.md
├── agent-service/
├── frontend/
├── evaluation/
├── docker-compose.yml
├── .env.example
├── AGENTS.md
├── DEVELOPMENT_PLAN.md
├── CHANGELOG.md
└── README.md
```

三个代码目录暂时包含 `.gitkeep`，用于让 Git 跟踪空目录。

## 开始之前

1. 阅读 `docs/PROJECT_TASK_BOOK.md`。
2. 根据任务书补充产品需求和技术选择。
3. 将 `.env.example` 复制为 `.env`，仅在本地填写真实配置。
4. 按 `DEVELOPMENT_PLAN.md` 分阶段开发和提交。

## 当前状态

仓库骨架已建立，尚未初始化应用代码。
